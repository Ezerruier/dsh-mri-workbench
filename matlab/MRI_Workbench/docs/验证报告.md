## 4. 人工 QC（可缩放，参考 DPARSF）

- 三类检查：T1 原始像（`T1Img/<subj>/c*` → `QC/RawT1ImgQC.tsv`）、功能平均像（`RealignParameter/<subj>/mean*` → `QC/RawFunImgQC.tsv`）、标准化检查（wFun/wT1/wGM + DPABI MNI 边缘轮廓 → `QC/NormalizationQC.tsv`），与 DPARSF/DPABI `y_spm_image`、`y_QC_Normalization` 的评分规则与文件格式兼容（1–5 分 + 评语，3 列 Tab）。
- 缩放：滚轮 + 拖拽 + [－][1:1][＋][适应]；`setZoomFactor` 中心缩放、`getZoomFactor` 由 axes 范围反推（2.5× 断言通过，交互后仍准确）。
- 集成：主界面第⑥页与 `mrw.QcViewer.open()` 独立窗口均实测可创建、可评分；`tests/test_qc_integration_lead.m` → `QC_INTEGRATION_RESULT=SUCCESS`。

## 6. 已知限制（不影响交付）

1. 交互式步骤（交互重定向、交互 ROI、FieldMap）依赖原生 GUI；工作台后台运行会自动关闭这些交互选项并在运行前检查中提示。
2. 运行前检查无法覆盖所有引擎内部失败（例如数据损坏导致的 SPM 作业失败）；此时日志会完整回传，按 `docs/DPARSFA_ENGINE.md` §6 排查。
3. 原生界面下拉框选项保留英文（回调可能依赖字符串），悬停提示提供中文解释。
4. 未在真实 DICOM 数据上端到端验证 DICOM→NIfTI 转换（本机无真实 MRI 数据；转换路径由官方引擎执行，工作台只负责参数与布局）。
5. 中文/空格路径会给出警告（dcm2niix/BET 等外部工具兼容性未知）。
6. 人工 QC 的标准化轮廓要求图像在 MNI 空间（非 MNI 时轮廓为空，不报错）；中文评语 UTF-8 保存，DPABI 原生工具按系统编码读取时可能乱码（纯英文无影响）。
