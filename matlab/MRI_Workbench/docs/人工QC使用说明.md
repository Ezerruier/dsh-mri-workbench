# 人工 QC 使用说明（v3：方向 / 交互 / 安全应用到数据）

> 目标：在预处理之后快速人工检查 T1、功能像与标准化质量，按 DPARSF 的 1–5 分体系评分并写评语，最后按阈值筛出可进入统计的被试名单。
> 图像查看支持**普通滚轮切层、Ctrl+滚轮锚点缩放、单击定位十字线、拖拽平移、活动视图按钮缩放、窗宽窗位**；保留三正交联动、原点/AC-PC 配平、多切片、FD、评分筛选和状态 JSON。
> 方位调整默认**只影响显示**。只有在「方位校准…」中点击「应用到数据…」并确认，才会创建独立输出副本；源图像始终不覆盖。

| 入口 | 说明 |

## 2. 三类检查（与 DPARSF 对应）

| 模态 | 显示的图像（DPARSF 规则） | 评分文件 |
|---|---|---|
| T1 原始像 | `T1Img/<受试者>/c*.nii`（co*；没有则 Crop/任意单张） | `QC/RawT1ImgQC.tsv` |
| 功能平均像 | `RealignParameter/<受试者>/mean*.nii`（没有则由 `FunImg` 4D 计算平均，界面会提示） | `QC/RawFunImgQC.tsv` |
| 标准化检查 | wFun = `RealignParameter/<受试者>/wmean*.nii`；wT1 = `T1ImgNewSegment/<受试者>/w*`（排除 wc*）；wGM = `wc1*.nii`；叠加 DPABI `Templates/Edge_mni_icbm152_AllTissues_tal_nlin_asym_09c_YCG.nii` 轮廓 | `QC/NormalizationQC.tsv` |

标准化检查的使用方式与 DPABI `y_QC_Normalization` 相同：主体灰阶图为受试者标准化图，彩色轮廓为 MNI 模板边缘；若轮廓与脑边界贴合良好说明标准化可接受。可在右上切换 wFun / wT1 / wGM，并调整轮廓透明度。

## 3. 界面操作

### 3.1 视图模式（工具条「视图模式」下拉）

- **单视图**：普通滚轮切层，Ctrl+滚轮缩放，单击定位，拖拽平移；支持方向下拉、切片滑条和窗宽窗位。
- **三正交（轴/冠/矢）**：左上水平位（Axial）、右上冠状位（Coronal）、左下矢状位（Sagittal）。位置与校准信息收为紧凑摘要。三个视图共享体素十字线，各自保留缩放和平移；滚轮作用于指针所在视图并把它设为活动视图。活动边框、方向标题和倍数帮助识别当前视图；滑条、↑/↓ 和缩放按钮控制活动视图。
- **多切片网格**：当前方向的等间隔切片拼图（montage），点击任一 tile 选层；当前十字线所在 tile 有高亮边框。

单击在释放鼠标时定位；移动距离达到 3 像素后按拖拽平移处理，十字线不变。双击或「适应」恢复活动视图的完整范围；「1:1」按显示像素与屏幕像素比例设置。

方向基准为本机 SPM `spm_image` 的 World Space 正交显示：横断图前方在上、右侧在右，冠状图上方在上、右侧在右，矢状图前方在左、上方在上。native 和经过方位变换的显示使用同一约定；斜切或负轴头信息按世界坐标重采样显示，native 表示未增加显示层变换，并不承诺逐像素直接切原始矩阵。坐标仍以源体素的 1-based 几何为准。

### 3.2 十字线与坐标读数

- 十字线位置 = 当前 3D 体素位置；三正交/多切片模式下自动联动。
- **坐标读数行**（图像区上方）实时显示：
  - **体素**：1-based 连续体素坐标 `[i j k]`（与 SPM/DPARSF 一致）；
  - **世界**：由 `hdr.mat` 换算的 mm 坐标；
  - **显示**：经原点/AC-PC/平移旋转/翻转后的显示 mm 坐标。
- 勾选「显示十字线」或按 `X` 键开关；方位调整后十字线仍以**体素坐标**为准，切片序号自动换算。**单视图同样绘制十字线**（与三正交/多切片共用同一体素位置，开关/`X` 键同样生效）。

### 3.3 原点校准与 AC-PC 配平（「方位校准…」按钮）

点中列或右列的 **方位校准…** 打开 modeless 对话框（标题「方位校准（AC-PC / 原点 / 手动）」）：

- 只读坐标读数：体素 / 世界 / 显示 mm（随面板同步刷新）；
- **以十字线设显示原点**：把当前十字线位置设为显示原点（显示模式变为 `origin`）；
- **把当前位置设为 AC / 把当前位置设为 PC**：分别拾取前连合（AC）与后连合（PC）的体素位置；
- **应用 AC-PC 配平**：按 AC→原点、PC→后方（-Y）计算显示变换，保持右(+X)/前(+Y)/上(+Z)约定（显示模式变为 `acpc`），只读显示 AC/PC 坐标、**AC-PC 距离（mm）与配平角度**、配平后的旋转/平移值；
- **清除配平**：回到原始方位（native）；
- AC 与 PC 距离过小时会给出中文提示且不配平（不会报错崩溃）；
- 默认仅预览；需要导出当前几何时使用「应用到数据…」，详情见后文。预览、重置和关闭窗口均不改源图像。

### 3.4 方位微调、色阶与插值

- 对话框内 6 个数值框：**平移**（右/前/上，mm）、**旋转**（pitch/roll/yaw，度）；「应用微调」「清零微调」。
- **翻转**复选框：左右翻转（放射学↔神经学）、前后翻转、上下翻转。
- 显示工具行的 **色阶**：灰阶（默认，DPABI 风格）/ 热色 / jet 彩色；**插值**：线性插值 / 最近邻（世界坐标切面需要重采样时生效）。
- **重置方位**按钮（或 `R` 键）：清除 AC-PC/原点/平移/旋转/翻转，恢复 native 显示。

### 3.5 受试者列表：筛选、排序与 MeanFD

- 表格列：`受试者 | 评分 | MeanFD`；MeanFD 超阈值时红色显示（来自 `RealignParameter/HeadMotion.tsv` 第 21 列）。
- **筛选下拉**：全部 / 仅未评分 / 已评分 / **低分≤阈值** / **MeanFD 超阈值**；「仅显示未评分」复选框等价于筛选到「仅未评分」。
- **排序下拉**：受试者 ID（自然排序）/ 评分↑ / 评分↓ / MeanFD↑ / MeanFD↓；没有评分或头动数据的受试者排在最后。
- 筛选/排序只影响列表显示，不修改已保存评分。

### 3.6 评分区与阈值导出

- 1 很差、2 差、3 一般、4 好、5 很好；评语自由文本（可留空）。
- 「保存并下一人」（写入 TSV 并在当前筛选列表中推进）、「跳过」。
- 当前受试者 Mean FD 与超阈值提示。
- 阈值设置（T1/Fun/标准化最低分默认 3；MeanFD 阈值默认 0.2）与「导出通过名单」（一行一个受试者 ID，可直接作为后续统计的被试列表）。

### 3.7 底部 FD 曲线与头动联动（新增，可折叠）

- 逐帧 FD 折线图：当前受试者 FD 值 + 阈值红虚线 + 坏帧红点；x 轴为帧号（删初始点后 1-based），y 轴为 mm。
- **FD 类型**下拉：FD_Jenkinson / FD_Power / FD_VanDijk；**坏帧阈值**数字框（Jenkinson/VanDijk 默认 0.2 mm，Power 默认 0.5 mm）。
- 统计文本：**MeanFD(TSV)**（`RealignParameter/HeadMotion.tsv` 第 21 列，与右侧 Mean FD 一致）、**序列均值**（逐帧 FD 序列的均值）、最大 FD、坏帧数/占比、最大平移/旋转；MeanFD(TSV) 与序列均值分开展示（两者可能略有差异）。
- 切换表格行/上一人/下一人时曲线同步；与评分联动：低分（≤2）时曲线标题加红色警示（确定性提示，不伪造结论）。

### 3.8 快捷键（图像窗口获得焦点、非文本输入框时）

| 按键 | 作用 |
|---|---|
| ↑ / ↓ | 活动视图切片（单视图同 v1） |
| ← / → | 上一人 / 下一人 |
| Home / End | 首 / 末切片 |
| 1–5 | 给当前受试者评分 |
| Enter | 保存并下一人 |
| A / C / S | 三正交模式下切换活动视图为 水平/冠状/矢状 |
| X | 十字线开关 |
| R | 重置方位（显示层） |

### 3.9 状态输出：「复制状态给 Agent」

- 工具条按钮 **复制状态给 Agent**：把当前 QC 状态（受试者/模态/视图模式/十字线/AC-PC/窗宽/叠加/FD/评分）以 JSON 文本复制到剪贴板，可直接粘贴进 DSH 对话；页脚会提示已复制。
- 窗口在状态变化（切换受试者/模态/视图、移动十字线、校准、评分等）后会把同一份状态**自动写入** `<工作目录>/QC/.qcviewer_state.json`（先写 `.json.tmp` 再原子替换；写入失败静默，不弹窗）。
- 状态 JSON schema 见第 5.3 节；DSH 侧读取工具为 `mri_workbench_qcstate`、命令为 `/mri qcstate`。

## 4. 评分文件格式（DPARSF 兼容）

```
<工作目录>/QC/RawT1ImgQC.tsv            Subject ID    QC Score    QC Comment
<工作目录>/QC/RawFunImgQC.tsv           Subject ID    QC Score    QC Comment
<工作目录>/QC/NormalizationQC.tsv       Subject ID    QC Score    QC Comment
```

- Tab 分隔、UTF-8；分数 1–5；文件可被 `DPABI_QC_TOOL` 读取（用于按阈值过滤/导出）。
- 评分写入方式为“读取已有行 + 更新当前受试者 + 整体重写”，不会清空其他受试者的评分。
- 阈值设置保存在 `QC/ManualQC_thresholds.json`。

## 5. Agent 实时指导（DSH）

### 5.1 怎么用

1. 在 MATLAB 里打开人工 QC 窗口（`/mri qc`、页面 ④「打开 MATLAB 人工 QC」或 `mrw.QcViewer.open(...)`），并**操作一次**（切换受试者/切片/视图、移动十字线、做 AC-PC 或方位校准、评分）——窗口会自动写出 `QC/.qcviewer_state.json`。
2. 在 DSH 对话里直接问，例如：
   - 「MATLAB 人工 QC 窗口现在显示的是什么？三正交对齐吗？帮我看看十字线位置和 AC-PC 距离。」
   - 「把当前显示设为 AC-PC 配平后，AC 角度是多少？接下来怎么微调？」
   - 「这个受试者的 FD 曲线有几个坏帧？和当前评分对得上吗？」
3. Agent 先抓真实桌面截图，再读取同一时刻的精确状态，结合两者给指导。本地 Codex 可用 PowerShell 截图或 computer-use，并用 Node 读取 `<工作目录>/QC/.qcviewer_state.json`，无需 DSH 专用工具。DSH 环境也可使用 `matlab_snapshot` 与 `mri_workbench_qcstate`（或 `/mri qcstate`）。截图用于检查图像、方向与轮廓；状态用于读取体素/世界 mm、AC-PC、显示矩阵和窗宽数值。

> 也可以在窗口点 **复制状态给 Agent**，把剪贴板里的 JSON 直接粘贴到对话；Agent 会把粘贴内容当作状态数据读取。窗口未打开或尚未操作时，工具会明确返回中文提示，Agent 不会编造状态。

### 5.2 工具与命令

- Agent 工具 **`mri_workbench_qcstate`**（参数 `workDir?`；缺省取最近一次「生成配置」或「数据扫描」的工作目录）
  - **不启动 MATLAB**，只读 `<workDir>/QC/.qcviewer_state.json`；
  - 返回结构化 JSON（受试者/模态/视图模式/十字线体素·世界·显示/切片/显示模式/AC-PC 距离角度/显示矩阵/平移旋转翻转/窗宽色阶插值缩放/叠加/FD 类型与坏帧/评分与进度/筛选排序/更新时间）**和中文摘要**；
  - 文件缺失、JSON 损坏、超过 **30 分钟**未更新时：中文友好提示 + 操作建议，不抛异常。过期时仍会显示上次内容，但会明确标注「可能已过期，仅供参考」。
- 命令 **`/mri qcstate [工作目录]`**：输出与工具相同的中文摘要。
- 页面 ④ 卡按钮 **「读取 MATLAB QC 状态」**：执行 `/mri qcstate` 并在页面「执行输出」区显示摘要，方便不通过对话也能快速看一眼。

### 5.3 状态 JSON（schema v2）概要

写入位置：`<工作目录>/QC/.qcviewer_state.json`（原子写入；`schema = "mrw.qcviewer.state.v2"`，`version = 2`）。主要字段：

| 字段 | 含义 |
|---|---|
| `updatedAt` / `workDir` | 最后更新时间（ISO 8601，带时区）/ 工作目录 |
| `modality` / `subjectID` / `subjectIndex` / `subjectCount` / `file` | 当前模态、受试者、序号与文件 |
| `viewMode` / `activeOrientation` | `single`/`triple`/`montage`；活动方向 `axial`/`coronal`/`sagittal` |
| `crosshairVoxel` / `crosshairWorld` / `crosshairDisplay` | 十字线体素（1-based）、世界 mm、显示 mm |
| `display` | `mode`(native/origin/acpc)、`matrix`(4×4)、`acVoxel`/`pcVoxel`、`acWorld`/`pcWorld`、`distanceMm`、`angleDeg`、`manualTranslationMm`、`manualRotationDeg`、`flips`、`hasVolume` |
| `slices` | 三方向当前切片 index/count |
| `window` / `clim` / `colormap` / `interp` / `zoom` / `crosshairVisible` | 窗宽、色阶范围、色阶、插值、缩放、十字线显示 |
| `overlay` | 模板轮廓可见/透明度/标准化图类型 |
| `score` | 当前分 `current` 与已保存分 `saved` |
| `headMotion` | `fdType`/`fdThreshold`；逐帧 `values`；`meanFD` = `RealignParameter/HeadMotion.tsv` 第 21 列（与窗口右列显示、通过名单一致；缺失时退回序列均值），`seriesMeanFD` = 逐帧序列均值，`meanFDSource` 标明来源（`HeadMotion.tsv#meanFD_Jenkinson`）；`maxFD` / `badFrames` / `badRatio` 为逐帧序列口径；`maxTranslation` / `maxRotation` |
| `filter` / `sort` / `progress` | 当前筛选/排序；三模态评分进度 |

> DSH 读取端对缺失字段、字段改名（如 `headMotion`/`FD`、嵌套 `crosshair`/`acpc`）、schema 不一致都做了容错：缺字段显示「—」，schema 不一致会给出提醒但仍尽量读取，并在摘要中标注。

### 5.4 状态更新与过期规则

- 打开窗口和切换受试者/切片/视图、移动十字线、校准、评分等操作会写状态；连续交互可合并中间状态，释放鼠标与滑条结束时写入最终位置。
- DSH 侧以 `updatedAt` 判断新鲜度：超过 **30 分钟**未更新视为过期（MATLAB 窗口可能已关闭或未再操作），会提示先操作一次。`updatedAt` 正常为本地时区偏移（如 `+08:00`）；若检测到异常时区标记，DSH 会自动按本地时间解读，不会把新鲜度判断反。
- 状态文件是「显示层快照」，**不含诊断结论**：Agent 只能转述坐标/数值并给操作建议，QC 评分与结论必须由人工给出。

## 6. 与 DPARSF 手动 QC 的差异

- DPARSF 的原始 T1/功能 QC 依赖交互式重定向流程（`y_spm_image`，仅 GUI 模式）；本工作台把它独立成可随时打开的人工 QC 审查，**不需要重跑预处理**。
- 增加了三正交联动、原点/AC-PC/方位校准、多切片网格、FD 曲线联动、排序筛选、滚轮/拖拽/按钮缩放、窗宽百分位、标准化轮廓透明度、评分进度与阈值导出等易用性功能。
- 评分尺度、文件命名与 DPARSF 完全一致，可与 DPABI 的 QC 工具链混用。
- 方位预览与状态 JSON 是显示层/辅助信息；v3 显式确认「应用到数据」只生成当前图像副本，不替换 DPARSF 产物与评分 TSV。

## 7. 限制

- 人工 QC 只查看已有 NIfTI 产物：DICOM 原始数据需先转换（工作台预处理或 DPARSF 转换后）才有图像可看。
- 标准化模态需要先做标准化（或提供 wFun/wT1/wc1 产物）；非 MNI 空间时模板轮廓为空（不报错）。
- **显示层变换默认非破坏性**：AC-PC/原点/平移/旋转/翻转只在确认「应用到数据」时生成副本；窗宽、色阶与屏幕缩放不会写进图像。该功能不替代配准或标准化流程。
- **AC/PC 需人工拾取**：本窗口只提供「在当前十字线位置设 AC/PC」与配平计算，不自动检测 AC/PC；拾取点不准会得到错误的角度，请结合三正交视图核对。
- **状态只在窗口操作后更新**；MATLAB 窗口关闭/长时间不操作时 DSH 读到的是旧状态（>30 分钟会提示过期）。截图与状态可能相差若干秒，快速连续操作时以状态 JSON 的 `updatedAt` 为准。
- 中文评语以 UTF-8 保存；DPABI 原生工具若按系统编码读取可能出现乱码（纯英文评语无此问题）。
- 模板缓存约 34 MB（首次加载）；超大 4D 数据切切片可能变慢。
- MATLAB 桌面 GUI 若已打开，需要重启 MATLAB 才能加载新增/修改的 `+mrw` 类文件（DSH 页面与工具不需要重启，但 MATLAB 侧窗口要重新打开）。

## 8. 把当前显示变换应用到数据

在「方位校准…」点击 **应用到数据…**。未增加任何显示变换时按钮禁用；有原点、AC-PC、微调或翻转时可用。确认摘要列出当前受试者、模态、源文件、显示模式、4×4 world→display 矩阵、微调/翻转、输出位置与回退办法。

范围仅限**当前受试者、当前模态、当前显示的单张 3D 图像**。其它图像/中间产物需单独应用或重跑受影响步骤，否则几何可能不一致。4D 时间平均预览不能直接应用到整个 4D 文件，请先生成明确的 3D 图像。

- 默认 **只重写 NIfTI 头**：复制原文件，体素强度和存储数据不变，将 `A * 源 SPM mat` 写入 qform/sform，同时写有效 codes。SPM 的 mat 是 1-based，NIfTI 头是 0-based，转换由 SPM NIfTI API 处理。
- 高级选项 **重采样体素副本** 默认关闭：按 QcView 实际显示网格插值，文件名包含 `_resampled`。插值有损、不可逆，体素数和体积可能变化；它与只改头使用不同输出批次。
- 输出规则为 `<工作目录>/QC/Reorient/<受试者>/<唯一批次>/<文件名>`，支持 `.nii`、`.nii.gz` 和 `.img/.hdr` 成对文件。先暂存、校验并写 `reorient_log.json`，再整体发布批次目录；相同名称的已有批次不会覆盖，源图像也不会覆盖。
- 写出前后检查源文件 SHA-256/大小；只改头另外检查体素数据一致，检查 SPM、DPABI 和 NIfTI 头几何。NIfTI-1头采用单精度存储，允许正常的编码量化，但实际sform、qform相对目标及彼此的全视野坐标偏差均不能超过0.001 mm；确认窗口和日志会记录上限及实际偏差。不能由qform表示的剪切、编码读回不一致或坐标偏差超限会明确拒绝并清理暂存输出。无需仅为正常的单精度量化误差改用重采样。
- 日志记录源/输出、方法、显示矩阵、时间、MATLAB 版本与校验摘要。导出后当前 QC 窗口继续预览原图，避免重复应用；下游需明确选择新副本。

**回退**：下游重新选择日志中的源图像即可。确认无需输出后，可删除该唯一批次目录；原始文件始终保留。若下游已基于新几何生成中间产物，回退时需重新运行相应步骤。日志及副本不会自动修改其它受试者、其它模态或现有流水线配置。
