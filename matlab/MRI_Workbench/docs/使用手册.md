# MRI 静息态分析工作台 · 使用手册

本手册面向第一次使用本工作台的静息态 fMRI 研究者。工作台本身不实现算法：**所有预处理计算由 DPABI 官方 DPARSFA_run 引擎完成**，工作台负责中文界面、悬停解释、自动索引、参数校验、后台运行与日志展示。

---

## 1. 安装与启动

### 1.1 环境要求

| 组件 | 说明 |
|---|---|
| MATLAB | R2020b+，本机验证 R2026a |
| SPM12 | DPABI 依赖，需在 MATLAB 路径中 |
| DPABI | 需包含 `DPARSF/DPARSFA_run.m`；本机为 V10.0_260625 |

### 1.2 启动

```matlab
cd('<仓库>\matlab\MRI_Workbench')
StartWorkbench          % 打开工作台
```

首次启动后到「⑤ 设置与帮助」确认环境状态为绿色；若 DPABI/SPM12 未找到，填写根目录并点「保存路径并重新检测环境」（保存到 `config/settings.json`）。

## 2. 数据准备规范

DPARSF 的目录约定是 **“模态目录在前、受试者目录在后”**：

```
<工作目录>/
  FunRaw/<受试者ID>/         功能像：DICOM 文件 或 NIfTI
  S2_FunRaw/<受试者ID>/     第 2 个 session（如有多 run）
  T1Raw/<受试者ID>/          T1 结构像（DICOM）
  BIDS/                     BIDS 根目录（可选）
```

- **DICOM 原始数据**：功能像放 `FunRaw/<ID>/`，结构像放 `T1Raw/<ID>/`；在「预处理参数 → 基础设置」勾选两个 DICOM→NIfTI 转换。
- **NIfTI 数据**：
  - 若已转换好，放 `FunImg/<ID>/`（4D 或逐卷 3D `.nii/.nii.gz`）与 `T1Img/<ID>/`，起始目录名填 `FunImg`、关闭 DICOM 转换；
  - 已有 `T1Img` 但没有 `co*` 时：DPABI 的「结构像裁剪」步骤现在调用 dcm2niix（只支持 DICOM），对 NIfTI 的 `T1.nii` 不会生成 `co*`，后台运行会因引擎弹出确认框而失败。请把「结构像处理 → **T1 裁剪兼容模式**」设为 **旧版 dcm2nii（可裁剪 NIfTI）**（运行前用 DPABI 自带旧版 dcm2nii 真实重定向+裁剪生成 `c*/co*`），或设为 **免裁剪**（把未裁剪 T1 复制为 `c*` 直通副本，不重定向/去颈，分割质量需人工 QC）；「运行前检查」会提前拦截错误配置。
- **BIDS 数据**：`<工作目录>/BIDS/sub-<ID>/[ses-xxx/]{func,anat}`，预处理时勾选「BIDS 数据转 DPARSF 结构」。
- 同一被试目录**不要混放** DICOM 与 NIfTI；T1Img 里只保留一个 T1 文件。
- 中文/空格路径：引擎字符串拼接可用，但调用 dcm2niix/dcm2nii/BET 等外部工具时建议避免。

> 原生 DPARSFA 需要用户一步步选择工作目录、逐个确认；本工作台在「① 数据索引」中自动搜索识别上述布局并一键填入，**不需要手动指定**。

## 3. 工作流程

### ① 数据索引

1. 选择“搜索根目录”（可以是被试数据的上一级，如 `D:\Data\MyStudy`）；
2. 设置扫描深度（默认 6）；
3. 点「开始自动扫描」：自动识别布局、受试者、功能/结构像目录、TR、时间点、层数；
4. 表格中检查每个受试者的目录/时间点/TR/状态，摘要区看 warnings；
5. 点「应用到预处理参数」，自动填充工作目录、受试者列表、起始目录名、session 数、TR、时间点、层数、DICOM 转换开关等。

也支持「导出索引 JSON」用于记录/审计。

> **直接扫描阶段目录（续跑模式）**：搜索根目录也可以直接填已处理的功能像目录（如 `<工作目录>\FunImgARB`）。工作台会自动按续跑解释：工作目录取其上级目录、起始目录名取该目录名（如 `FunImgARB`），并从各受试者的 4D NIfTI 头读取 TR/时间点/层数；结构像自动在上级目录的 `T1Raw/T1Img/AnatRaw/<受试者>` 中查找。若要续跑多 session 数据，建议仍扫描完整工作目录。

### ② 预处理参数

- 顶部选择**预设**：经典静息态（DARTEL）、仅功能像（EPI 标准化）、BIDS 一键预处理、快速质控；选择后会覆盖流程相关开关（保留数据/受试者信息）。
- 参数按 7 个子选项卡分组：基础设置、时间层与头动、结构像处理、标准化与平滑、回归与滤波、指标计算、高级与运行。
- **每个参数悬停都有解释**（来源：`resources/glossary.tsv`）；不理解的英文术语可到「④ 术语库」检索。
- 灰色不可编辑的参数表示依赖未满足（例如未勾选“时间层校正”时层数/层序不可编辑）。
- 顶部“将执行”摘要实时显示当前流程链；字段搜索框可按名称/英文/key 定位参数。
- 支持「保存配置」（.mat，可被原生 DPARSFA 载入）与「导入配置」。

### ③ 运行与日志

1. 先点「运行前检查」：显示错误 / 提醒 / 通过项；有错误时不能开始。
2. 「开始预处理」：工作台保存 `runs/run_时间戳/Cfg.mat`，启动独立 MATLAB 进程执行官方引擎；主界面不冻结。
3. 日志区实时滚动（含 SPM 作业输出），状态条显示当前阶段、进度、已用时。
4. 「取消运行」会终止后台进程树；已生成的中间结果保留。
5. 结束后可「打开输出目录」查看结果；按钮「打开运行目录」查看 cfg/log/status.json。

### ④ 术语库

143 条术语（98 个参数 + 45 个通用概念），可搜索、按分类筛选，右侧显示与参数悬停一致的解释、默认值、推荐值与来源。用于学习 DPABI 英文术语，也用于核对参数含义。

### ⑤ 设置与帮助

- 环境状态、DPABI/SPM 路径、并行工具箱是否正确；
- 原生界面汉化开关、允许交互开关、扫描深度；
- 「打开原生 DPABI / DPARSF 高级版 / DPARSF 经典版」：打开后自动汉化（翻译静态文本/按钮/复选框并加中文悬停解释；下拉框保留英文取值以防破坏回调，但悬停有中文说明）。

## 4. 预设说明

| 预设 | 适用 | 关键步骤 |
|---|---|---|
| 经典静息态（DARTEL 全流程） | 有 T1 的常规静息态数据（DICOM） | 删前 10 点 → realign → T1 统一分割+DARTEL 标准化 → 平滑 4mm → 回归 → 0.01–0.1Hz 滤波 → ALFF/fALFF、ReHo |
| 仅功能像（EPI 模板标准化，无结构像） | 只有功能像，或不想用 T1 | 删前 10 点 → realign → EPI 模板标准化 → 平滑 → 滤波 → ALFF |
| BIDS 数据一键预处理 | BIDS 数据集 | 自动转 DPARSF 结构后走经典 DARTEL 流程 |
| 快速质控（仅转换+头动校正） | 数据体检/筛被试 | 删前 10 点 → realign；产物 `RealignParameter/HeadMotion.tsv` 等 |
| 空白（仅补步骤/续跑） | 已有中间结果，只想补做某一步 | 所有处理与指标默认关闭；先把「起始目录名」设为已有阶段目录（如 `FunImgAR`），再只勾选要补的步骤（如 Scrubbing、ALFF、ReHo）并设置参数。不会删除/重做数据，但需自己保证起始目录与时间点匹配。 |

时间层校正默认关闭：需要在「时间层与头动」中按扫描参数开启并填写层数/层序/参考层（引擎层数为 0 时使用高危默认隔层序，工作台会给提醒）。

## 5. 结果与续跑

- 输出遵循 DPARSF 规范：`FunImg`（转换）、`FunImgA`（切片）、`FunImgAR`（realign）、`FunImgARW`（标准化）、`FunImgARWS`（平滑）、`FunImgARWSC`（回归）、`FunImgARWSCF`（滤波），指标在 `Results/*_<目录名>/`，头动指标在 `RealignParameter/`。
- 续跑：将「起始目录名」改为上一步产物目录（如 `FunImgARW`）并关闭前面已完成的步骤即可从该步骤继续；具体后缀链见 `docs/DPARSFA_ENGINE.md` §4.2。想快速进入续跑状态可先选「空白（仅补步骤/续跑）」预设，再改起始目录并勾选要补的步骤。
- **T1 裁剪兼容模式**（「结构像处理 → T1 裁剪兼容模式」，默认「自动」）用于绕过 DPABI 191121 之后的一个已知限制：裁剪步骤改为调用 dcm2niix（只支持 DICOM），当 `T1Img/<ID>/` 只有 NIfTI 的 `T1.nii` 时不会生成 `c*/co*`，无界面运行会在 BET/分割阶段因无法弹出确认框而失败（`DPARSFA_run.m:1641` 附近）。两种可选模式：
  - **旧版 dcm2nii（可裁剪 NIfTI）**：运行前用 DPABI 自带的 `DPARSF/dcm2nii/dcm2nii.exe`（2016 版，支持 NIfTI 输入）对每名受试者的 T1 做重定向+裁剪，真实生成 `c*/co*`；然后关闭 DPARSF 自带的裁剪步骤，避免 dcm2niix 再跑。推荐优先使用。
  - **免裁剪**：不做裁剪，把未裁剪 T1 复制为 `c*` 直通文件，让引擎继续运行（不重定向/去颈，分割与标准化质量需人工 QC）。
  - 两种模式都只对「需要 T1 的流程」生效；使用 T1Raw DICOM 转换时会被忽略（转换阶段会自动生成 co*）。页面「参数设置…（弹窗）」或 `/mri prepare <预设> T1CropCompat=old_dcm2nii` 均可设置。
- 运行前检查（预检）会识别已处理阶段目录（`FunImgA/AR/ARB...`）：若从 `FunImg` 重跑「删除初始时间点」会报 error（会再次原地裁剪数据）；`RealignParameter` 中同一受试者存在多个 `rp*.txt` 时，重跑头动校正会报 error（FD 计算会因 rp 文件过多失败）；续跑模式会检查所需 FD 文件是否齐全。检查未通过时运行会被阻止，需先修正配置、清理目录或改用续跑。
- DARTEL 需要整批被试一起跑：增减被试后应整批重跑。

## 6. 在 DeepSeek Harness（DSH）中使用

工作台也可以直接在 DSH 里操作，计算仍然由 MATLAB + DPARSF 高级版后台完成（详见 [DSH 集成说明](DSH集成说明.md)）：

- 插件：`dsh-mri-workbench`（已安装到 `desktop` profile；刷新一次 DSH 页面后，会话视图出现「MRI 工作台」标签页）；
- 页面：数据扫描 → 选择预设 →（可选）点「参数设置…（弹窗）」在 DPARSF 风格参数面板里手动调参（分组导航、中英文对照、悬停解释、依赖联动）→「生成配置并校验」→ 启动/取消预处理 → 刷新状态；长任务实时日志显示在会话顶部「后台任务」；
- Agent：`mri_workbench_env / scan / prepare / start / status / wait / cancel / open_gui` 工具；
- 命令：`/mri help` 查看全部子命令；
- 需要 MATLAB 原生界面（完整悬停解释、术语库、交互步骤）时，用 `/mri open` 或页面「打开 MATLAB 桌面版」。

## 7. 人工 QC（可缩放，参考 DPARSF）

预处理完成后，用「⑥ 人工QC」或顶部「人工QC」按钮/「运行与日志 → 打开人工QC」进入人工检查（也可在命令窗口 `mrw.QcViewer.open(工作目录)` 单独打开）。

- **三类检查**（与 DPARSF/DPABI QualityControl 对应）：
  1. `T1 原始像`：`T1Img/<受试者>/c*` 首张 → 写入 `QC/RawT1ImgQC.tsv`
  2. `功能平均像`：`RealignParameter/<受试者>/mean*` → 写入 `QC/RawFunImgQC.tsv`
  3. `标准化检查`：`RealignParameter/<受试者>/wmean*`（wFun）、`T1ImgNewSegment/<受试者>/w*`（wT1）、`wc1*`（wGM），叠加 DPABI MNI 边缘模板轮廓 → 写入 `QC/NormalizationQC.tsv`
- **可缩放查看**：鼠标滚轮缩放、拖拽平移、`[－][1:1][＋][适应]` 按钮、切片滑条、方向切换（横断/冠状/矢状）、窗宽低/高百分位调节与自动窗宽；标准化检查可开关模板轮廓并调透明度。
- **评分**：与 DPARSF 一致 1 很差 / 2 差 / 3 一般 / 4 好 / 5 很好，附评语；「保存并下一人」自动推进；左侧列表显示评分，可筛选未评分。
- **阈值与名单**：设置 T1/Fun/标准化最低分（默认 3）与 MeanFD 阈值，导出通过被试名单（文本，一行一个 ID），格式与 DPABI_QC_TOOL 的名单一致。
- **兼容性**：评分 TSV 为 3 列 Tab（`Subject ID / QC Score / QC Comment`），可被 `DPABI_QC_TOOL` 直接读取（中文评语以 UTF-8 保存）。
- DSH 中可用 `/mri qc` 打开 MATLAB 人工 QC 查看器，`/mri qcstatus` 或 `mri_workbench_qc` 工具汇总评分。

## 8. 常见问题（排错）

| 现象 | 原因/解决 |
|---|---|
| 顶部状态显示 DPABI 未找到 | 「设置」中手动指定 DPABI 根目录（含 dpabi.m 的目录），保存并重新检测 |
| 运行前检查报“输入数据类型”错误 | 数据是 DICOM 但未勾选转换，或 NIfTI 却勾了转换；按提示调整 |
| 报“T1Img 中只有原始 T1（无 co*）” | 把「结构像处理 → T1 裁剪兼容模式」设为「旧版 dcm2nii（可裁剪 NIfTI）」或「免裁剪」；或改用 DICOM 原始 T1（引擎转换会自动生成 co*） |
| 报“裁剪步骤调用 dcm2niix 只支持 DICOM” | 同上：NIfTI T1 无法被 dcm2niix 裁剪，改用「旧版 dcm2nii（可裁剪 NIfTI）」或「免裁剪」模式 |
| 报“TR 需手动填写” | NIfTI 头无 TR（pixdim4=0）：在「基础设置」填 TR 秒数，或勾选时间点=0 |
| 后台运行弹出“无法创建阻塞对话框” | 引擎内部确认框；按运行前检查修正 T1 形态/切片序等后重试 |
| 运行中途失败 | 「运行与日志」看日志尾部；`runs/.../run.log` 有完整输出；可对照 `docs/DPARSFA_ENGINE.md` §6 的失败模式 |
| 取消后想继续 | 已生成中间目录结构可续跑（见 §5） |
